# vantak — портфолио

Авторский сайт разработчика Владислава Ящишена: работы, информация обо мне и прямые контакты.

Это готовые статические файлы для GitHub Pages. Публикация: ветка main, папка /(root). Файл .nojekyll отключает обработку Jekyll.

Основные данные меняются в content.js: имя, контакты, логотип, изображения, описания и ссылки проектов. Изображения находятся в assets/.

Работающий сайт Yung Lean находится в projects/yung-lean/. Компьютерный и мобильный скриншоты в портфолио открывают соответствующую версию сайта. Для обновления встроенного проекта замените его папку новой статической сборкой.

Лицензия шрифта портфолио — assets/OFL.txt. Лицензии шрифтов и сведения о фотографии встроенного проекта — projects/yung-lean/assets/licenses/.


Интерактивная демоверсия «Сойдёмся» находится в `projects/soidemsya/index.html`, её сборка — в `assets/soidemsya-*`. Скриншоты открывают выбранный размер экрана. Демоверсия работает без сервера: встречи, пожелания, голоса и изменения каталога сохраняются в localStorage посетителя. Панель демо позволяет переключать участников, открыть подготовленный пример и сбросить локальные данные. Приглашения не переносят встречи на другие устройства. Каталог — снимок исходного проекта от 25 октября 2026 года. Лицензии React — `assets/soidemsya-LICENSE.txt`.
